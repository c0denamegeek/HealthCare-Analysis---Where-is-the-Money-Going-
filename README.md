# HealthCare-Analysis-Claims---Where-is-the-Money-Going-
We are losing money and we want to figure out why! This dashboard will help the C-Level Executives see where we are bleeding money and try to become profitable again. They'd like this dashboard in Tableau or Power BI, but preferably Tableau.

Questions to Answer
Which claim types are the most expensive?

Which CPT and ICD codes drive the highest spending?

Which members account for the largest share of total costs?

How do billed amounts compare to paid amounts?

For this project, I used Excel, SQL and Power BI. 

I used Excel and SQL to transform the data and query for answers to answer the questions. Power BI to create the dashboard for the stakeholders.
